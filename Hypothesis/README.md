## Research Gap 우선순위 및 실험 결과 상세

### H2 — RUL 클리핑 (부분 채택)

**가설:** clip=125가 CMAPSS 전 데이터셋에서 최적 RUL 클리핑 임계값이다.  
**결과:** clip=125가 FD001/FD003에서 명확히 최적; FD002/FD004에서 clip=130과 통계적 동등 (p=0.97).  
clip=None은 FD003 NASA Score 4,014,724 (clip=125 대비 306,000× 폭증).  
**의의:** Cross-dataset 검증 최초 수행 + clip=None 재앙 메커니즘 규명.

### H5 — 정규화 전략 (기각)

**원래 가설:** Per-unit 정규화가 Fleet 정규화보다 우수하다.  
**실제 결과:** 반대 — Fleet MinMax(N1)이 FD001/FD002/FD004 모두에서 통계적으로 유의하게 최우수.  
Per-unit (N3–N6)과 RevIN (N7)은 모두 N1 대비 열세 (BH p<0.05, Cohen's d ≥ 1.66).  
**추가 발견:** FD003에서 N1의 이상 분산(std=12.86)은 정규화 실패가 아닌 고장 모드 이종성 신호.  
**해결 사항:** 서브그룹(lifetime < 150) 분석 완료; fleet 정규화가 열화 궤적 정보를 보존함을 확인.

### H6 — 고장 모드 분리 (채택 — M3)

**가설:** FD003/FD004에서 비지도 고장 모드 분리가 단일 모델보다 우수하다.  
**결과:** M3 Attention Gate가 FD003 RMSE −65.8% (14.78±1.32 vs 43.23±0.18 baseline).  
초기 K=10 사이클만으로 라우팅 → 커미셔닝 시점 적용 가능; K=5로도 충분 (14.23±0.34).  
M1(Hard routing)은 FD004에서 cluster collapse로 실패 (49.20±7.17, baseline 28.05 대비 역효과).  
**추가 EDA 확인:** FD003 GMM k=2 Silhouette=0.761 (강한 분리), BIC 최적 k=2 확인.

### H7 — 손실 함수 (기각)

**가설:** 비대칭/가중 손실 함수가 MSE보다 NASA Score를 유의하게 개선한다.  
**결과:** BH-FDR 보정 96개 비교 모두 p_BH > 0.05 (통계적 유의성 없음).  
RUL 클리핑이 손실 함수 선택을 압도 — clip=125 고정 시 7개 손실 함수 모두 1.5× 이내로 수렴.  
**해결 사항:** life_ratio는 훈련 시에만 사용, 추론 시 None으로 설정 — 올바른 설계 확인.

## 3계층 설계 계층구조 (논문 핵심 기여)

H2/H5/H6/H7 실험이 공동으로 확립한 우선순위:

```
TIER 1 — 레이블 엔지니어링 (clip=125)   ← 잘못되면 NASA Score 최대 30만 배 폭증
TIER 2 — 고장 모드 아키텍처 (M3)       ← 최대 −65.8% RMSE
TIER 3 — 손실 함수 (MSE 기본값)        ← 통계적으로 유의한 이득 없음
```

각 티어의 달성 가능한 레버리지가 다음 티어를 질적으로 초과.

## 미실험 가설 (H3, H4)

H3 (클러스터 정규화)과 H4 (PCA)는 Tier 2로 분류되어 논문 범위에서 제외됨.  
H5 실험에서 K-means residualization (FD002/FD004)은 공통 전처리로 적용 완료.
